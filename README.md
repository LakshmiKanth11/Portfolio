# 🚀 Lakshmi Kanth V — Data Analyst Portfolio

A professional, single-page portfolio website with an **antigravity aesthetic** — dark theme, floating particles, a glowing custom cursor, and premium glassmorphism design. Built to showcase data analytics projects, skills, and experience.

🔗 **Live Site:** 

---

## ✨ Features

- 🌌 **Antigravity aesthetic** — dark theme with floating orbs and a particle canvas background
- 🖱️ **Custom cursor** — glowing dot-and-ring cursor that follows mouse movement
- 🪟 **Glassmorphism UI** — frosted-glass cards and panels throughout
- ⌨️ **Typing animation** — animated role text in the hero section
- 📊 **Animated skill bars** — visual proficiency indicators for tools & technologies
- 📱 **Fully responsive** — mobile-friendly navigation with hamburger menu
- 🎬 **Scroll reveal animations** — sections fade/slide into view on scroll
- 🧩 **Case study cards** — structured project breakdowns (Problem → Approach → Tools → Insights → Outcome)

## 🚀 Getting Started

### Run locally

No build tools or dependencies are required — it's a static site.

```bash
git clone https://github.com/LakshmiKanth11/Portfolio.git
cd Portfolio
```

Then simply open `index.html` in your browser, or serve it locally:

```bash
# Using Python
python -m http.server 8000

# Using Node (npx)
npx serve .
```

Visit `http://localhost:8000` in your browser.

### Deploy

This site can be deployed for free on any static hosting platform:

- **GitHub Pages** — enable Pages in repo settings, pointing to the `main` branch
- **Netlify** — drag and drop the folder or connect the repo
- **Vercel** — import the repo as a static project
